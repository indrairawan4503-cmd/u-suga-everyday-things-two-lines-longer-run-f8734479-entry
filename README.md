**A toaster is a stand-up tanning booth for bread** — a two-line explanation of an everyday thing for a 10-year-old. Line 1 explains the toaster through one concrete, surprising analogy; line 2 says honestly what that analogy maps and what it leaves out.

## Run it

```sh
python3 main.py
```

It writes the two-line text to `/output/entry.txt` (and a byte-identical copy to `entry.txt` next to the script when the directory is writable).
